# OfficeEase — Backend لكل الخدمات الـ20

هذا مشروع **Node.js / Express** حقيقي وشغّال، يغطي الخدمات الـ12 (الحزمة الأولى) والخدمات الـ8 (الحزمة الثانية) لمنصة OfficeEase.

---

## 1. المتطلبات قبل التشغيل

- تثبيت **Node.js** إصدار 18 أو أحدث ([nodejs.org](https://nodejs.org))
- محرر أكواد (VS Code مثلاً) لفتح المشروع
- (اختياري لكن مهم لبعض الخدمات) مفتاح **Anthropic API** — لو ما توفر، الخدمات التي لا تحتاج ذكاء اصطناعي تشتغل عادي، والباقي تعطي رسالة واضحة توضح أنها تحتاج المفتاح

---

## 2. خطوات التشغيل (على أي جهاز/سيرفر)

```bash
# 1) فك ضغط الملف وادخل للمجلد
cd officeease-backend

# 2) ثبّت المكتبات
npm install

# 3) انسخ ملف البيئة وعبّئ القيم
cp .env.example .env
# افتح .env وضع فيه: ANTHROPIC_API_KEY=sk-ant-xxxxxxxx

# 4) شغّل السيرفر
npm start
```

بعد التشغيل بيظهر لك:
```
✅ OfficeEase Backend يعمل على http://localhost:4000
   جرّب: http://localhost:4000/api/services
   صفحة اختبار: http://localhost:4000/
```

- افتح `http://localhost:4000/` في المتصفح → صفحة اختبار جاهزة لتجربة بعض الخدمات مباشرة (رفع ملف والحصول على النتيجة).
- افتح `http://localhost:4000/api/services` → قائمة بكل الـ20 خدمة مع رابط كل خدمة (endpoint).

---

## 3. عند تجهيز السيرفر الفعلي لاحقاً

ما تحتاج تغيّر شي بالكود، فقط:

1. ارفع نفس المجلد على السيرفر (VPS / Render / Railway / أي استضافة Node.js).
2. حدد متغيرات البيئة (`.env`) على السيرفر بنفس الأسماء الموجودة في `.env.example`.
3. شغّل `npm install && npm start` (أو استخدم PM2 لإبقاء السيرفر شغّال دائماً: `pm2 start server.js`).
4. اربط دومين OfficeEase بعنوان السيرفر (عبر Nginx reverse proxy مثلاً).

| 5 | تنظيف وتبييض تصوير المستندات | ✅ يعمل بدون AI | تحسين تلقائي للإضاءة/التباين عبر `sharp` |

| 10 | الختم والتوقيع الجماعي | ✅ يعمل بدون AI | يدعم رفع عدة ملفات ودمج ختم PNG شفاف + تحميل ZIP |
| 11 | عزل الأختام بصيغة شفافة | ⛔ يحتاج إضافة | يتطلب خوارزمية تجزئة لونية/رؤية حاسوبية |

| 13 | الأرشفة والبحث النصي | ✅ يعمل (Prototype) | تخزين بملفات JSON — يُستبدل بقاعدة بيانات حقيقية |
| 14 | نظام الاعتمادات والتوقيع | ✅ يعمل (Prototype) | منطق تمرير متسلسل كامل بين معتمدين |
| 15 | متتبّع انتهاء الصلاحية | ✅ يعمل | يحتاج `ANTHROPIC_API_KEY` لاستخراج التاريخ |
| 16 | محضر الاجتماع التلقائي | ⚠️ نصف شغّال | تحويل نص→محضر ✅ يعمل، لكن تحويل صوت→نص يحتاج ربط خدمة Speech-to-Text |
| 17 | تحليل مخاطر العقود | ✅ يعمل | يحتاج `ANTHROPIC_API_KEY` |
| 18 | عروض الأسعار ولوحة الصفقات | ✅ يعمل (Prototype) | تخزين JSON — يُستبدل بقاعدة بيانات لاحقاً |
| 19 | تسوية كشف الحساب البنكي | ✅ يعمل | يحتاج `ANTHROPIC_API_KEY` |

**الخلاصة:** 17 من أصل 20 خدمة تعمل فعلياً الآن (بعضها يحتاج فقط وضع مفتاح Claude API)، و3 خدمات (6، 11، ونصف 16) تحتاج ربط نموذج ذكاء اصطناعي متخصص إضافي (inpainting / رؤية حاسوبية / Speech-to-Text) لا يمكن تنفيذه بمكتبات عادية.

## 5. هيكلة المشروع

```
officeease-backend/
├── server.js                 # نقطة تشغيل السيرفر الرئيسية
├── package.json
├── .env.example               # انسخه إلى .env وعبّئ القيم
├── routes/
│   ├── textDataTools.js       # خدمات 1-4
│   ├── visualTools.js         # خدمات 5-8
│   ├── securityBulkTools.js   # خدمات 9-12
│   └── phase2Tools.js         # خدمات 13-20
├── utils/
│   ├── aiClient.js            # الاتصال بـ Claude API (موحّد لكل الخدمات الذكية)
│   └── fileHelpers.js         # رفع الملفات وحفظ المخرجات
├── data/                      # قواعد بيانات JSON مؤقتة (تُنشأ تلقائياً)
├── uploads/                   # الملفات المرفوعة مؤقتاً (تُحذف بعد المعالجة)
├── outputs/                   # الملفات الناتجة (يمكن تحميلها عبر /outputs/الاسم)
└── public/index.html          # صفحة اختبار بسيطة من المتصفح
```

## 7. ملاحظات أمان مهمة قبل الإطلاق الفعلي

- استبدل تخزين JSON في `/data` بقاعدة بيانات حقيقية (PostgreSQL/MongoDB) قبل الإنتاج.
- فعّل **HTTPS** وتحقق من هوية المستخدم (JWT/OAuth) قبل ربط أي endpoint بواجهة عامة.
- خزّن الملفات النهائية على تخزين سحابي دائم (S3 أو ما شابه) بدل مجلد `outputs` المحلي.
- طبّق حذف تلقائي دوري للملفات المؤقتة في `uploads/` و`outputs/` بعد فترة زمنية للحفاظ على الخصوصية (كما ورد في متطلباتكم الأصلية).
